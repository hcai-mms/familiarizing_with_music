# Familiarizing with Music
Code and Data for reproducing experiments for our paper "Familiarizing with Music: Discovery Patterns for Different Music Discovery Needs".

# Code 
The code to reproduce the analysis is available at [https://github.com/hcai-mms/familiarizing_with_music](https://github.com/hcai-mms/familiarizing_with_music) .

# Data
The dataset is publicly available on [Zenodo](https://zenodo.org/uploads/10160691) with [CC BY-NC-SA](https://creativecommons.org/licenses/by-nc-sa/4.0/) license (Creative Commons Attribution Non Commercial Share Alike 4.0 International).
