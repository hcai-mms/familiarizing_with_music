| Correlation and Pearson. While Pearson's correlation can be used with Likert scales, it assumes equal spacing between responses—an assumption that may not always hold. For example, is a self-declared interest in unfamiliar music rated as "4" equally distant from "5" and "3"? We do not know. Using Spearman’s correlation, which does not assume linearity or normally distributed data, may be a better approach.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Provide analysis in repo.                                                                                                                                                                                                                                                                                                                                                                                | 4              |   |   |

| Negative Feedback and Discovery I find it problematic to "only consider listening events that lasted longer than 30 seconds" and to "disregard user–track pairs (u, m) for which u listened to m only once." This suggests that a discovery is only valid when users like what they hear, whereas discovering something one dislikes is still an essential part of the exploration process. Skipping a track after 25 seconds is still a discovery—it indicates resistance to unfamiliar content. Likewise, listening to a song just once may still indicate a successful discovery. These preprocessing decisions seem driven more by computational convenience than scientific reasoning (i.e. the justification that "30 seconds is a threshold often applied in music streaming for remuneration purposes" is not scientifically valid). I recommend reconsidering these preprocessing choices. | Maybe say we will do this in the extension?                                                                                                                                                                                                                                                                                                                                                              | 4              |   |   |
